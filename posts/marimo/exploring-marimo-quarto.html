##### Types of Conjugation
A Spanish verb changes its ending to show who is doing something (the *person*) and when or how it happens (the *tense* and *mood*). I found the [Spanish Language Tutor](https://youtu.be/FRV9fvWjMHA?si=AljiKHJo_7orl4f8) and [Ella Verbs](https://ellaverbs.com/resources/spanish-verb-tenses-in-english/)  helpful references here. Spanish has manyyy tenses spread across three moods (indicative, subjunctive, imperative). To keep it simple and to scaffold my learning appropriately, the tool below will conjugate the nine simple tenses that [Wiktionary](https://en.wiktionary.org/wiki/Appendix:Spanish_verbs#) lists for every verb. Specifically I adapt a method from the [Spanish Language Tutor](https://youtu.be/FRV9fvWjMHA?si=AljiKHJo_7orl4f8) where the singular and plural versions are split into a 2 X 3 grid - this approach makes it easier to remember how things line up. 

| | Singular | Plural |
|---|---|---|
| **1st person** | yo (I) | nosotros / nosotras (we) |
| **2nd person** | tú (you, one person, informal) | vosotros / vosotras (you, more than one person, informal; mostly used in Spain) |
| **3rd person** | él / ella / usted (he, she, or *you* when being formal with one person) | ellos / ellas / ustedes (they, or *you* for more than one person) |

Note that *Usted* and *ustedes* mean "you" but take the third-person form, so *usted habla* is "you speak".

While the grid itself is simple, there are *9* different versions that it can take depending on the tense and mood of the sentence. Luckily, with `marimo`, we have the capacbilities to quickly switch between the 9 different version. The tool below also has a **Tenses and moods** tab that lists the nine tenses by mood, with an example of when to use each one.

#| echo: false
_verb = verb_lookup.get(word.value)

if _verb is None:
    _output = mo.md("Pick a verb above to see its conjugations.")
else:
    _forms = _verb["conjugations"][tense.value]
    _persons = data["meta"]["persons"]

    def _cell(person):
        return mo.stat(_forms.get(person, "—"), label=_persons[person], bordered=True)

    # Singular on the left, plural on the right, as in most textbooks.
    _grid = mo.vstack(
        [
            mo.hstack([_cell(singular), _cell(plural)], widths="equal")
            for singular, plural in [
                ("yo", "nosotros"),
                ("tu", "vosotros"),
                ("el", "ellos"),
            ]
        ]
    )
    _header = mo.md(
        f"### {_verb['infinitive']} {'(irregular)' if _verb['irregular'] else ''}\n\n"
        f"{_verb['glosses'][0]}. "
        f"Gerund *{_verb['gerund']}*, past participle *{_verb['past_participle']}*."
    )
    _output = mo.vstack([tense, _header, _grid])

##### Etymology
Wiktionary also records where each verb came from. For verbs inherited from Latin, the Latin entry lists its descendants across the Romance languages (and the odd English borrowing), which makes a family tree of related words. The **Etymology** tab shows that tree for the verb you pick, with its own branch highlighted. This is sometimes incredibly helpful, as some words share pretty close similarities with English and can be a nicer aid to memory. For example hablo (to speak) comes from the latin fabulari - which is the root of the english word fable (a story). While not the same, we can see the similarities. 



```{python .marimo}
#| echo: false
from html import escape

ROW, COL, PAD = 30, 220, 16
ACCENT = "#3987e5"


def etymology_tree(verb):
    """The verb's Latin cognate tree, or failing that its line of ancestors."""
    if verb["cognates"]:
        return verb["cognates"]
    if not verb["ancestors"]:
        return None
    node = {"lang": "Spanish", "code": "es", "word": verb["infinitive"], "children": []}
    for ancestor in verb["ancestors"]:  # newest first, so build from the verb upwards
        node["borrowed"] = ancestor["relation"] in ("borrowed", "learned borrowing")
        node = {**ancestor, "children": [node]}
    return node


def _without_groups(node):
    # Grouping nodes ("Ibero-Romance") have no word; lift their children up a
    # level to keep the tree narrow.
    children = []
    for child in node.get("children", []):
        child = _without_groups(child)
        children.extend(child["children"] if child["word"] is None else [child])
    return {**node, "children": children}


def etymology_svg(verb):
    tree = _without_groups(etymology_tree(verb))
    placed = []
    next_row = 0

    def place(node, depth):
        nonlocal next_row
        child_ids = [place(child, depth + 1) for child in node["children"]]
        if child_ids:
            row = (placed[child_ids[0]]["row"] + placed[child_ids[-1]]["row"]) / 2
        else:
            row, next_row = next_row, next_row + 1
        is_target = node["code"] == "es" and node["word"] == verb["infinitive"]
        placed.append(
            {
                "node": node,
                "row": row,
                "x": PAD + depth * COL,
                "y": PAD + 20 + row * ROW,
                "children": child_ids,
                "target": is_target,
                "on_path": is_target or any(placed[i]["on_path"] for i in child_ids),
            }
        )
        return len(placed) - 1

    place(tree, 0)

    # Each parent gets one trunk out to a spine, then a branch to each child,
    # so a borrowed (dashed) branch never runs over a shared trunk.
    edges = []
    for p in placed:
        if not p["children"]:
            continue
        spine = p["x"] + COL - 20
        edges.append((p["on_path"], f"M{p['x']},{p['y']} H{spine}", False))
        for c in (placed[i] for i in p["children"]):
            edges.append(
                (
                    c["on_path"],
                    f"M{spine},{p['y']} V{c['y']} H{c['x']}",
                    c["node"].get("borrowed"),
                )
            )

    parts = []
    # Highlighted edges last, so they sit on top.
    for on_path, d, borrowed in sorted(edges, key=lambda e: e[0]):
        stroke = (
            f'stroke="{ACCENT}" stroke-width="2.5"'
            if on_path
            else 'stroke="currentColor" stroke-opacity="0.35" stroke-width="1.5"'
        )
        dash = ' stroke-dasharray="5 4"' if borrowed else ""
        parts.append(f'<path d="{d}" fill="none" {stroke}{dash}/>')
    for p in placed:
        n = p["node"]
        word, lang = escape(n["word"]), escape(n["lang"])
        tip = f"{lang}: {word}" + (" (borrowed)" if n.get("borrowed") else "")
        fill = (
            f'fill="{ACCENT}"'
            if p["on_path"]
            else 'fill="currentColor" fill-opacity="0.55"'
        )
        parts.append(
            f'<circle cx="{p["x"]}" cy="{p["y"]}" r="{6 if p["target"] else 4}" {fill}><title>{tip}</title></circle>'
        )
        weight = "700" if p["target"] else "400"
        # Leaves are labelled beside the node; parents above their trunk,
        # clear of the edges to their children.
        x, y = (p["x"] + 8, p["y"] - 7) if p["children"] else (p["x"] + 10, p["y"] + 4)
        parts.append(
            f'<text x="{x}" y="{y}" font-size="13">'
            f'<tspan font-weight="{weight}">{word}</tspan>'
            f'<tspan dx="6" font-size="11" fill-opacity="0.65">{lang}</tspan></text>'
        )
    width = max(p["x"] for p in placed) + 260
    height = PAD * 2 + 20 + (next_row - 1) * ROW + 20
    return (
        f'<svg viewBox="0 0 {width} {height}" width="{width}" style="max-width:100%;height:auto;color:var(--bs-body-color, inherit)" '
        f'fill="currentColor" font-family="inherit" role="img" '
        f'aria-label="Etymology tree for {escape(verb["infinitive"])}">{"".join(parts)}</svg>'
    )
```

| Tense | Spanish name | Used for | Example |
|:---|:---|:---|:---|
| Present | presente | current situations, habits, general truths | *Hablo* español. (I speak Spanish.) |
| Preterite | pretérito indefinido, also called pretérito perfecto simple | actions completed at a specific time | Ayer *hablé* con ella. (I spoke to her yesterday.) |
| Imperfect | pretérito imperfecto | habits, descriptions and ongoing actions in the past, "used to" | De niño *hablaba* francés. (As a child I used to speak French.) |
| Future | futuro simple | future actions, and guesses about the present | Mañana *hablaré* con él. (I'll speak to him tomorrow.) |
| Conditional | condicional simple | hypotheticals, polite requests, wishes | *Hablaría* más si tuviera tiempo. (I'd speak more if I had time.) |
| Present subjunctive | presente de subjuntivo | doubt, wishes, feelings and uncertainty about the present or future | Quiero que *hables* más despacio. (I want you to speak more slowly.) |
| Imperfect subjunctive | pretérito imperfecto de subjuntivo | the same uses in the past, and "if" clauses about unlikely situations | Si *hablara* mejor, viajaría más. (If I spoke better, I'd travel more.) |
| Imperative | imperativo afirmativo | commands and instructions | ¡*Habla* más alto! (Speak up!) |
| Negative imperative | imperativo negativo | telling someone not to do something, using *no* with the present subjunctive | ¡No *hables*! (Don't speak!) |

There is no *yo* command, so in the imperatives that card shows a dash.

Descriptions adapted from [Ella Verbs](https://ellaverbs.com/resources/spanish-verb-tenses-in-english/).
"""
